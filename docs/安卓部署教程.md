# 安卓部署教程

把一台闲置的安卓手机变成 Uranus iMessage 的服务器，24 小时在线，不用电脑、不用云服务器、不花钱。

---

## 先搞清楚谁干什么

这件事需要两台设备，**它们之间不直接通信**：

| 设备 | 角色 | 要求 |
|---|---|---|
| **安卓手机** | 服务器。跑 Uranus，连模型、连 Photon 线路 | 64 位（2019 年以后基本都是）、3 GB 以上空闲、能连 Wi-Fi、能一直插电 |
| **苹果设备** | 聊天客户端。你用它跟角色聊天 | 登录了 iMessage 的 iPhone / iPad / Mac，任意一台 |

安卓那台**不需要 SIM 卡**，只要 Wi-Fi 和电。苹果那台**不需要装任何东西**，就是平时发 iMessage 的「信息」App。

角色的号码是 Photon 分配的线路（在控制台 iMessage 面板里拿），你从苹果设备发消息给那个号码，服务在安卓上算出回复，再从那条线路发回来。安卓和苹果全程没有任何直接连接。

> ⚠️ **这条路适合「手机常年插着电放在家里」**。如果你会带着这台手机出门、或者它要正常当手机用，那服务会随着你锁屏、切 App、出门断网而中断。那种情况请看 [VPS 部署教程](VPS部署教程.md)。

## 1. 装 Termux

Termux 是安卓上的 Linux 终端，Uranus 就跑在它里面。

### 1.1 一定要从 F-Droid 装

**别从应用商店装。** Google Play 上那个是另一套代码（`termux-play-store`），受安卓沙箱限制更多，局域网访问有已知问题。

去 [f-droid.org/packages/com.termux](https://f-droid.org/packages/com.termux/) 下载 APK，或者从 [GitHub Releases](https://github.com/termux/termux-app/releases) 下最新的 `termux-app_v*+apt-android-7-github-debug_arm64-v8a.apk`。

手机会提示「未知来源」，去设置里允许一下就行。

顺手把 **Termux:Boot** 也装上（[F-Droid 链接](https://f-droid.org/packages/com.termux.boot/)），第 7 节开机自启要用。

> ⚠️ **两个 App 必须来自同一个来源。** F-Droid 版和 GitHub 版签名不同，混装的话 Termux:Boot 认不出 Termux，开机自启会静默失效。

### 1.2 第一次打开

打开 Termux，等它自己初始化完，出现 `$` 提示符就可以开始敲命令了。

先更新一下软件源：

```bash
pkg update && pkg upgrade -y
```

中间会问几次「要不要保留现有配置文件」，一路回车用默认的就行。

## 2. 装运行环境

```bash
pkg install nodejs-lts git ffmpeg -y
```

这一条装了三样：

- **nodejs-lts** —— Node 的长期支持版。**别装 `nodejs`**（那是最新版），原生模块在最新版 Node 上经常编译不过。
- **git** —— 用来下载项目和以后更新。
- **ffmpeg** —— 语音条转码要用。这是 Termux 自己编译的安卓版，项目会自动找到它（原因见第 3 节）。

验证一下：

```bash
node -v && ffmpeg -version | head -1
```

Node 版本出现 `v22.x` 或 `v24.x` 都行，ffmpeg 出现一行版本号就对了。

## 3. 下载项目并改两处依赖

### 3.1 下载

```bash
cd ~ && git clone https://github.com/nikonotnicotine/Uranus_Imessage.git && cd Uranus_Imessage
```

### 3.2 为什么必须改

`server/package.json` 里有两个依赖在安卓上装不上，**不改的话 `npm install` 会直接失败，一个包都装不进去**：

| 依赖 | 为什么装不上 | 删掉有什么影响 |
|---|---|---|
| `ffmpeg-static` | 它的安装脚本去 GitHub 下 `android-arm64` 的预编译二进制，而上游**没有**这个平台的构建，404 之后脚本直接报错退出 | **没影响。** 项目找 ffmpeg 的顺序是「`FFMPEG_BIN` 环境变量 → 这个包 → 系统 PATH」，删掉它会自动用第 2 节装的系统 ffmpeg |
| `@spectrum-ts/imessage-local` | 它间接依赖 `better-sqlite3`，那个要现场用 node-gyp 编译，Termux 上会因为 `android_ndk_path` 未定义而失败 | **没影响，前提是走云端模式。** 这个包是「本地 Mac 模式」用的（直接读 macOS 的 `chat.db`），安卓上压根用不到 |

> 💡 云端模式就是默认的那个：控制台 iMessage 面板填 Photon 的 projectId / projectSecret。本地 Mac 模式只在 Mac 上有意义，见 [Mac 部署教程](Mac部署教程.md)。

### 3.3 改

一条命令改完：

```bash
sed -i '/"ffmpeg-static"/d; /"@spectrum-ts\/imessage-local"/d' server/package.json
```

确认改对了（应该看不到这两个名字，而且剩下的行末逗号要合法）：

```bash
cat server/package.json
```

`dependencies` 里现在应该是这些：

```json
  "dependencies": {
    "@napi-rs/canvas": "0.1.80",
    "@spectrum-ts/imessage": "^12.10.1",
    "chinese-days": "^1.5.9",
    "cors": "^2.8.5",
    "date-holidays": "^3.36.1",
    "express": "^4.21.2",
    "mammoth": "1.12.3",
    "nodemailer": "10.0.9",
    "pdf-parse": "2.4.5",
    "spectrum-ts": "^12.10.1",
    "tar-fs": "^2.1.5"
  }
```

> ⚠️ **每次更新项目之后要重新改一遍。** `git pull` 会把 `server/package.json` 恢复成原样，然后 `npm install` 又会失败。第 9 节给了一条把两步合一的命令。

## 4. 装依赖、构建、启动

### 4.1 装依赖

```bash
npm install
```

手机上这一步要 5–15 分钟，取决于网速和 CPU。**别锁屏、别切出去**，Termux 在后台可能被系统冻住（第 6 节会彻底解决这个问题，但现在还没配）。

装完如果看到几行 `npm warn` 是正常的，只要最后没有 `npm error` 就行。

> 💡 卡在某个包下不动，一般是网络问题。`Ctrl + C` 中断，然后重新跑一次 `npm install` —— 已经装好的会跳过，不会从头来。

### 4.2 构建前端

```bash
npm run build
```

这一步用 Vite 打包控制台页面，手机上大概 1–3 分钟。

### 4.3 启动

```bash
npm start
```

> 💡 别用 `启动.bat` 里那套一键启动（`node scripts/launch.mjs start`）—— 它会试着开浏览器，而 Termux 里没有桌面环境。`npm start` 只起服务，正是手机上要的。

看到这样几行就是起来了：

```
  → http://localhost:8787
  → Instagram: http://localhost:6873
```

**先别关这个窗口。** 第 6 节会讲怎么让它在后台常驻。

## 5. 第一次打开控制台

在**这台安卓手机自己的浏览器**里打开：

```
http://localhost:8787
```

默认账号密码都是 `Uranus`。

进去之后会**强迫你改密码**（跳不过去），要求**至少 8 位、至少一个大写字母**。不改的话除了改密码什么操作都做不了。

> 🔒 这个默认密码是公开写在文档里的。控制台里存着你全部的模型 API key 和 Photon 凭据，所以第 8 节把控制台开到公网之前，务必先把密码改成一个像样的。

改完按这个顺序填配置：

1. **连接** → 填模型 API 地址和密钥，把要用的模型加进清单
2. **iMessage** → 填 Photon 的凭据（projectId / projectSecret），拿到角色的线路号码
3. **角色** → 建角色，选人设、选模型、绑号码
4. **用户** → 填你自己是谁（提示词里的 `{{user}}`）

填完就可以从苹果设备发消息给第 2 步拿到的那个号码了。

> ⚠️ **安卓 16 及以上可能打不开 `localhost`。** 安卓从 16 开始收紧了本地网络访问（`ACCESS_LOCAL_NETWORK`），有用户报告外部 App 连不上 Termux 里的服务（[termux-app#4824](https://github.com/termux/termux-app/issues/4824)）。如果浏览器一直转圈或者秒拒，别折腾了，直接跳到第 8 节用 Cloudflare Tunnel —— 那条路走公网绕回来，完全不受这个限制。

## 6. 让它 24 小时不掉

这一节是安卓部署**最关键**的部分。安卓有四层机制会杀掉后台进程，少配一层，服务就会在某个半夜悄悄停掉。

### 6.1 Wake lock（防止深度睡眠）

```bash
termux-wake-lock
```

敲完通知栏里 Termux 那条通知会变样。这条命令让系统不进深度睡眠，否则息屏几分钟后 Node 的定时器就会被冻住 —— 表现是「主动开口」和「IG 定时刷」全不动了。

> ⚠️ **光有 wake lock 不够。** 它防的是睡眠，不防下面 6.3 那个「幽灵进程杀手」。

### 6.2 关掉电池优化

去安卓设置里，把 **Termux** 和 **Termux:Boot** 两个 App 的电池优化都关掉：

> 设置 → 应用 → Termux → 电池 → **无限制**（不同品牌叫法不一样：「后台活动不受限」「允许后台运行」「高耗电允许」）

国产 ROM 还要额外开「**自启动**」和「**允许后台弹出界面**」，并在最近任务里给 Termux **加锁**（下拉那个卡片，点锁图标）。

各家 ROM 的具体路径看 [dontkillmyapp.com](https://dontkillmyapp.com)，小米、华为、OPPO、vivo 都在上面。

### 6.3 关掉幽灵进程杀手（安卓 12 及以上，**最容易漏的一步**）

安卓 12 加了个看门狗，会用 `SIGKILL` 杀掉后台的子进程。症状很好认：Termux 里突然出现

```
[Process completed (signal 9) - press Enter]
```

`signal 9` 捕捉不了、拦不住，代码里做任何处理都没用。只能从系统层面关掉。

**做法是用 ADB 连自己**（不需要电脑）：

先开无线调试：设置 → 关于手机 → 连点「版本号」7 次开启开发者选项 → 开发者选项 → **无线调试** → 打开。

然后在 Termux 里：

```bash
pkg install android-tools -y
```

点开「无线调试」里的「**使用配对码配对设备**」，会显示一个**配对码**和一个**配对端口**，照着敲（端口和码换成你屏幕上的）：

```bash
adb pair localhost:37251 123456
```

配对成功后，回到「无线调试」主页看**连接端口**（⚠️ 跟配对端口**不是**同一个数字），然后：

```bash
adb connect localhost:41983
```

最后关掉它：

```bash
adb shell "settings put global settings_enable_monitor_phantom_procs false"
```

验证一下，应该输出 `false`：

```bash
adb shell "settings get global settings_enable_monitor_phantom_procs"
```

**这个设置重启后依然有效**，是一次性的。设完可以把无线调试关掉。恢复出厂设置之后要重做。

### 6.4 硬件上的两件事

- **开发者选项 → 不锁定屏幕**（插电时屏幕常亮）。很多省电策略是跟着息屏触发的，屏幕常亮能绕过一大堆。
- **把充电上限设到 80%**（三星：电池 → 电池保护；Pixel：电池 → 充电优化）。一台常年插电顶在 100% 的手机，电池鼓包是真实风险。

### 6.5 用 pm2 让它后台常驻

前面第 4.3 节那样直接 `npm start`，关掉 Termux 窗口服务就没了。用 pm2 管起来：

```bash
npm install -g pm2
```

启动：

```bash
cd ~/Uranus_Imessage && pm2 start npm --name uranus -- start
```

保存进程列表（开机自启要用）：

```bash
pm2 save
```

常用命令：

```bash
pm2 list          # 看状态
pm2 logs uranus   # 看日志（Ctrl+C 退出，不会停服务）
pm2 restart uranus
pm2 stop uranus
```

## 7. 开机自启

手机重启（系统更新、断电）之后自动把服务拉起来。

确认 **Termux:Boot 至少手动打开过一次** —— 装上不打开是不生效的，这一步是安卓授予开机权限的时机。

建目录并写启动脚本：

```bash
mkdir -p ~/.termux/boot
```

```bash
cat > ~/.termux/boot/start-uranus.sh <<'EOF'
#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
node /data/data/com.termux/files/usr/bin/pm2 resurrect
EOF
```

```bash
chmod +x ~/.termux/boot/start-uranus.sh
```

> 💡 **为什么要用 `node` 加绝对路径调 pm2**：开机时的环境变量极简，`PATH` 里找不到 `pm2`，直接写 `pm2 resurrect` 会静默失败。

重启手机验证，起来之后在 Termux 里敲 `pm2 list`，看到 `uranus` 是 `online` 就成了。

## 8. 在别的设备上打开控制台

平时想在电脑或 iPad 上改配置，有两条路。

### 8.1 同一个 Wi-Fi 下直连（简单，但不一定通）

查安卓的局域网 IP：

```bash
ifconfig wlan0 | grep 'inet '
```

在同一个 Wi-Fi 的设备上打开 `http://那个IP:8787`。

⚠️ 安卓 15/16 上这条**可能不通**（原因同第 5 节），而且很多家用路由开了「AP 隔离」，设备之间互相看不见。不通就走下面那条。

### 8.2 Cloudflare Tunnel（推荐，免费，且绕开所有本地网络限制）

它从手机主动连出去，给你一个公网 HTTPS 地址，任何设备任何网络都能开。**顺带解决安卓 16 连不上 localhost 的问题。**

```bash
pkg install cloudflared -y
```

> 💡 如果 `pkg` 里没有，去 [cloudflared releases](https://github.com/cloudflare/cloudflared/releases) 下 `cloudflared-linux-arm64`，`chmod +x` 之后放到 `$PREFIX/bin/`。

跑起来：

```bash
cloudflared tunnel --url http://localhost:8787
```

输出里会有一个 `https://xxxx-xxxx.trycloudflare.com` 的地址，那就是你的控制台。

> 🔒 **这个地址是公网可访问的。** 拿到地址的人只隔着一个登录框，而里面是你全部的 API key。**必须先改掉默认密码**（第 5 节），而且别把地址发到群里。
>
> 临时隧道每次重启地址都会变。要固定地址就得注册 Cloudflare 账号建命名隧道，那个也是免费的。

想让隧道也常驻，同样交给 pm2：

```bash
pm2 start cloudflared --name tunnel -- tunnel --url http://localhost:8787 && pm2 save
```

### 8.3 在国内的话

程序自己不带代理，所有请求都直连出去。

- **直连就通**：模型的国内中转站、Photon（iMessage 桥接）、天气、音乐
- **直连不通**：Instagram 面板抓真实内容、DuckDuckGo 联网搜索

要用那两样，得在**这台安卓手机上**开全局代理 —— Clash Meta / mihomo 之类的客户端请开 **TUN 模式**（安卓上就是那个「VPN」开关）。只在应用内设代理没用，Termux 里的 Node 不认。

联网搜索也可以在控制台里换成 Tavily / Brave，那两家国内直连就通，省得开代理。

> ⚠️ **代理和第 8.2 节的 Cloudflare Tunnel 会打架。** TUN 模式接管全部流量之后，`cloudflared` 的出站连接也会被绕进代理，隧道可能频繁断。如果两样都要，在代理客户端的规则里把 `*.trycloudflare.com` 和 `*.argotunnel.com` 设成直连。

## 9. 日常维护

### 9.1 更新到新版本

**别用 `更新.bat`**，那是 Windows 的。手机上这样：

```bash
cd ~/Uranus_Imessage && git pull && sed -i '/"ffmpeg-static"/d; /"@spectrum-ts\/imessage-local"/d' server/package.json && npm install && npm run build && pm2 restart uranus
```

中间那个 `sed` 就是第 3.3 节那两处改动 —— `git pull` 会把它们冲掉，所以每次更新都要重新删一遍。**漏了这一步 `npm install` 会失败。**

### 9.2 看日志

```bash
pm2 logs uranus --lines 100
```

### 9.3 备份数据

`data/` 里是全部身家：配置、密钥、角色、世界书、聊天存档。

```bash
cd ~/Uranus_Imessage && tar czf ~/uranus-backup-$(date +%Y%m%d).tar.gz data/
```

把生成的 `.tar.gz` 拷到手机存储里带走：

```bash
termux-setup-storage
```

```bash
cp ~/uranus-backup-*.tar.gz ~/storage/downloads/
```

第一条会弹权限申请，同意之后 `~/storage/downloads` 就指向手机的「下载」文件夹了。

> 💡 控制台里也有「云备份」功能（S3 / WebDAV），配好了就不用手动来这一套。

### 9.4 省点存储和内存

不用 Instagram 面板的话，把那个端口关掉：

```bash
pm2 delete uranus
```

```bash
cd ~/Uranus_Imessage && URANUS_IG_PORT=off pm2 start npm --name uranus -- start && pm2 save
```

## 10. 出问题了怎么办

### `npm install` 报 `node-gyp` / `android_ndk_path` 错误

第 3.3 节那两行没删干净。重新跑一次那条 `sed`，然后 `rm -rf node_modules && npm install`。

### `npm install` 报 `Failed to download ffmpeg` / 404

同上，`ffmpeg-static` 还在 `server/package.json` 里。

### 服务跑一会儿就没了，Termux 显示 `signal 9`

幽灵进程杀手没关掉，回去做 6.3。这是最常见的原因。

### 息屏之后角色不主动说话了，解锁就恢复

wake lock 没拿到。`termux-wake-lock` 敲一遍，并确认 6.2 的电池优化真的关了。国产 ROM 尤其要检查「自启动」那一项。

### 浏览器打不开 `localhost:8787`

先确认服务活着：

```bash
pm2 list && curl -s localhost:8787/api/health
```

`curl` 能返回 JSON 说明服务没问题，是浏览器这边被安卓的本地网络限制卡住了 —— 走第 8.2 节的 Cloudflare Tunnel。

`curl` 也连不上，看日志找原因：`pm2 logs uranus --lines 50`。

### 转账卡片没有 logo

`@napi-rs/canvas` 的安卓包没装上。单独补一下：

```bash
cd ~/Uranus_Imessage && npm install @napi-rs/canvas-android-arm64
```

其它功能不受影响，只是卡片少张图。

### 语音条时长显示 0 秒

ffmpeg 没找到。确认 `ffmpeg -version` 有输出；没有就 `pkg install ffmpeg -y`。

### 忘了控制台密码

```bash
nano ~/Uranus_Imessage/data/auth.json
```

把 `"password"` 那一行的值改成 `null`（或者干脆删掉整个文件），`Ctrl+O` 回车保存、`Ctrl+X` 退出，然后 `pm2 restart uranus`。密码就回到默认的 `Uranus`。

## 附：从零到跑起来的全部命令

配置类的步骤（第 1 节装 APK、6.2 关电池优化、6.3 配对 ADB）没法用命令代替，其余是这些：

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git ffmpeg android-tools -y
cd ~ && git clone https://github.com/nikonotnicotine/Uranus_Imessage.git
cd Uranus_Imessage
sed -i '/"ffmpeg-static"/d; /"@spectrum-ts\/imessage-local"/d' server/package.json
npm install
npm run build
npm install -g pm2
termux-wake-lock
pm2 start npm --name uranus -- start
pm2 save
```

然后去做 6.2、6.3、第 7 节，最后在浏览器里开 `http://localhost:8787` 改密码。
